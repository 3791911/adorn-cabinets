# Adorn Cabinets

Marketing website for Adorn Cabinets: frameless and framed kitchen cabinets in flat matte and high-gloss acrylic finishes, sold direct and wholesale.

Static HTML/CSS/JS. No build step required.

Pages: index (Home), cabinet-styles, finishes, direct-wholesale, direct-manufacture, for-the-pro (login, sign-up, plan upload, quote request; client-side demo only).

## Deploy on Netlify

1. Sign in at netlify.com and click **Add new site > Import an existing project**.
2. Choose **GitHub** and pick this repo (adorn-cabinets).
3. Leave the build settings empty (it is a static site) and click **Deploy**.
4. Your site goes live at a `netlify.app` URL. Add a custom domain in **Domain settings** when ready.

Contact details are placeholders until the real ones are added.
